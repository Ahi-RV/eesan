MANDRESH Help

Manhole Drawing Records & Engineering Search Hub

1. Search

Type a manhole number, cabinet number, road name, project number, drawing number, or keyword, then press Search. Use Advanced Search for Exact search when you only want direct text matches, or Broad search when spacing and separators may differ.

2. Filters

Use All, Manhole, Duct, Card, SLD, and Planmap to narrow results. All shows matching pages. Duct, Card, SLD, and Planmap show files from the matching drawing class.

3. Quick Preview

Select a result to preview the drawing. Use Hand to pan, Select to inspect indexed text, Find to search inside the selected PDF, zoom controls to enlarge the drawing, and fullscreen for detailed review.

4. Screenshot / Crop Export

Choose Visible area, Full page, or Crop area from the screenshot menu. For Crop area, drag a rectangle on the preview first, then press the screenshot button. The saved image includes the selected drawing area.

5. Index Tools

Use Index Tools to check health, failed files, duplicate files, same filename review, unknown classifications, relationship reports, CSV exports, and reindexing. Same filename removal is review-first; MANDRESH will not silently delete source files.

6. Indexing Workflow

Use Scan MANdrESH Folder after adding files. Use OCR Images for image drawings. Reindex Selected File or Reindex Current Folder for small updates. Use Backup + Full Rebuild only when rules or data structure changed significantly.
